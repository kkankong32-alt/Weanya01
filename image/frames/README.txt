왜냐면 과학실 1권 — 캐릭터 프레임 이미지
=========================================

원본 시트(image/player_*_sheet.png)는 칸이 일정하지 않고 인물끼리 붙어 있어서
프로그램이 자동으로 자르면 반드시 어긋납니다. 그래서 한 번만 잘라서 아래처럼
"포즈 1개 = 파일 1개"로 만들어 두었고, 게임은 시트가 아니라 이 파일들을 읽습니다.

  <캐릭터>_<동작>_<번호>.png      예: yeminhye_run_0.png

  캐릭터 : yeminhye / shinjunghan / yonggamhui
  동작   : run(달리기) / jump(점프) / misc(기타)


■ 고치는 방법
--------------
해당 PNG를 열어서 고치고 같은 이름으로 저장하면 끝입니다.

- 크기(해상도)는 아무래도 됩니다. 2배로 키워 저장해도 게임에서 크기가 안 바뀝니다.
  각 포즈의 화면 크기는 js/player_atlas.js 의 HEIGHTS 표에 고정되어 있고,
  파일은 "어떻게 생겼는지"만 결정합니다.
- 투명 여백도 아무래도 됩니다. 게임이 여백을 무시하고 그림이 있는 영역만 씁니다.
  발 아래 여백이 있어도 공중에 뜨지 않습니다.
- 배경은 반드시 투명(알파)으로 두세요.
- 가로세로 비율을 바꾸면 화면에서도 그만큼 넓거나 좁아집니다.
  (높이는 표에 고정, 너비는 그림 비율을 따라감)
  그래서 팔을 벌린 포즈는 자연히 넓게 나옵니다.
  반대로 캐릭터를 더 통통하게 보이고 싶으면 그림을 가로로 넓게 그리면 됩니다.

편집 후 아래를 실행하면 투명 여백이 정리되어, 편집기에서 보이는 모습과
게임에 나오는 모습이 똑같아집니다. (선택 사항 — 안 해도 게임은 정상)

  python trim_frames.py


■ 화면 크기를 바꾸고 싶으면
----------------------------
js/player_atlas.js 맨 위의

  var IDLE_H = 40;

이 값이 "가만히 서 있는 아이의 화면 높이(px)"입니다. 타일 하나가 16px이니
40이면 2.5칸 키입니다. 이 숫자만 바꾸면 세 캐릭터가 함께 커지거나 작아집니다.


■ 확인용 미리보기
------------------
_contact_<캐릭터>_<동작>.png 파일을 열면 원본 시트에 초록 네모로 "어디를 잘랐는지"
표시되어 있습니다. 자른 위치가 이상하면 그 프레임 PNG만 고치면 됩니다.


■ 게임에서 어떤 포즈를 쓰는지
------------------------------
run  : 0~5번을 순서대로 반복해 달리기
misc : 0번 = 가만히 서 있기
       2번 = 다쳤을 때
       마지막 번호 = 스테이지 클리어 만세
       (예민혜/용감희는 5번, 신중한은 4번 = misc가 5장뿐)
jump : 0번 = 웅크림(착지·앉기)
       예민혜(4장)   2번=상승, 1번=정점, 3번=하강
       신중한(6장)   2번=상승, 3번=정점, 4번=하강
       용감희(6장)   3번=상승/정점, 4번=하강

쓰는 포즈만 고쳐도 됩니다. 안 쓰는 번호(달리기 중간 포즈 등)는 그대로 둬도
게임에 영향 없습니다.

포즈 번호를 바꾸고 싶으면 js/player_atlas.js 의 각 캐릭터 pose: 부분을
고치면 됩니다.
